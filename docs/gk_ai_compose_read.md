## gk ai compose read

Show the patch bodies of collected hunks (no AI)

### Synopsis


Show the patch bodies of hunks listed by "gk ai compose collect", so you can
understand changes you did not write before authoring a plan. Read-only; no AI.

Select hunks with exactly one of --hunks (indices) or --file (paths). Output is
capped at --max-bytes (default 50000, max 200000); omitted hunks are listed in
omitted_indices (--json) so you can read them in another call. The first
selected hunk is always returned.

Fails with details.reason "stale_collection" if the changes were edited since
collect; run collect again.

--json returns {hunks[{index,file,header,content,binary}], truncated,
omitted_indices}.


```
gk ai compose read [flags]
```

### Examples

```

  gk ai compose read --based-on <token> --hunks 0,1 --workdir /path/to/repo
  gk ai compose read --based-on <token> --file src/main.go --json --workdir /path/to/repo

```
