## gk ai skill check

Check installed GitKraken skill integrity

### Synopsis

Report the state of each bundled GitKraken skill for the given AI coding tool.

The command never writes: it reads the skill file and the GitKraken metadata
beside it and reports one state per skill.

  missing        no skill file is installed
  current        installed and identical to this gk binary's bundled skill
  older_release  installed unchanged by an earlier gk release; update replaces it
  modified       edited, unowned, linked, or not written by gk; needs --force

Use --scope project to check the skills committed with the current Git
worktree instead of the ones installed for your user. Name several clients to
check each of them, or pass --all to check every detected client plus any
client that still has GitKraken skills installed. In project scope, --all
checks only clients with skills committed in the current worktree.

Supported clients: antigravity, antigravity-cli, augment, claude-cli, codex, copilot, cursor, grok, opencode, pi
Bundled skills: gitkraken-cli, gitkraken-commit-composer, gitkraken-resolve

```
gk ai skill check <client>... [flags]
```

### Examples

```
  gk ai skill check antigravity
  gk ai skill check antigravity --json
  gk ai skill check antigravity --skill gitkraken-cli
  gk ai skill check antigravity --scope project
```

### Options

```
      --all                 Check every detected client and every client with GitKraken skills installed.
  -h, --help                help for check
      --scope string        Check scope: global or project. (default "global")
      --skill stringArray   Bundled skill to check (can be repeated).
```
