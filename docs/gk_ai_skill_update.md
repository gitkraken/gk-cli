## gk ai skill update

Update installed GitKraken skills from this gk binary

### Synopsis

Refresh the GitKraken CLI skills already installed for the given AI coding tool.

Update only touches skills that are installed and that gk can prove it wrote
unchanged: a skill from an earlier gk release is replaced without --force. A
skill that is not installed is skipped, because installing it is what
'gk ai skill install' is for. An edited or unowned file is refused until you
pass --force.

Name several clients to update each of them, or pass --all to update every
client that currently has GitKraken skills installed.

Supported clients: antigravity, antigravity-cli, augment, claude-cli, codex, copilot, cursor, grok, opencode, pi
Bundled skills: gitkraken-cli, gitkraken-commit-composer, gitkraken-resolve

```
gk ai skill update <client>... [flags]
```

### Examples

```
  gk ai skill update antigravity
  gk ai skill update antigravity --dry-run
  gk ai skill update antigravity --skill gitkraken-cli
  gk ai skill update antigravity --force
```

### Options

```
      --all                 Update every client that has GitKraken skills installed.
      --dry-run             Preview update without writing.
  -f, --force               Replace modified owned skill files.
  -h, --help                help for update
      --scope string        Update scope: global or project. (default "global")
      --skill stringArray   Bundled skill to update (can be repeated).
```
