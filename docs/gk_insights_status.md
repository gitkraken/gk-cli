## gk insights status

Show how Insights telemetry is set up on this machine

### Synopsis

Show the stored Insights endpoint and email, whether a token is stored (the
token itself is never printed), and for every supported AI tool whether it is
installed, whether its telemetry is configured by gk, by managed settings or not
at all (unknown when its configuration cannot be read), and whether gk's configuration drifted from what "gk insights setup"
would write now (a hand edit, or a stale token, endpoint or email). A tool's
configuration counts as gk's by the same rule "gk insights uninstall" uses: it
has the shape setup writes and points at a gk host (the stored endpoint's, the
default's or any *.gitkraken.com), whatever token or email it carries.

It also shows whether git context is sent to Insights from the GitKraken Claude
Code hook.

With --check it also sends one test log record to the collector and fails with
the same meaning as setup: a rejected token exits 1, an unreachable or failing
collector (network error or HTTP 5xx) exits 75. Without --check it never fails
because of what it finds.

```
gk insights status [flags]
```
