## gk ai models

List the GitKraken-hosted AI models available for the model override

### Synopsis


List the models the GitKraken AI backend offers, including which is the default
and each model's token limits. Use a model id with `gk ai provider set gitkraken --model <id>`
to override the model used for all GitKraken-hosted AI calls.

The list is task-scoped on the backend (models are registered per task type);
this shows the models for the default task type, which is the set valid for the
GitKraken model override. Results are cached for 4 hours; use --refresh to
force a fresh fetch.


```
gk ai models [flags]
```

  gk ai models
  gk ai models --refresh
