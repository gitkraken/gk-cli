## gk provider projects

List the projects the authenticated user can access

### Synopsis


  Enumerate projects under the user's accessible orgs/sites. Azure DevOps and
  Jira expose a project layer; other providers are skipped. Without --org,
  every accessible Azure organization or Jira site is walked. --org filters
  to a single Azure DevOps organization or Jira site (matched by display name).

  Examples:
    gk provider projects azure
    gk provider projects azure --org myorg
    gk provider projects jira
    gk provider projects jira --org gitkraken --json


```
gk provider projects [provider] [flags]
```
