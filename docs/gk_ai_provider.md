## gk ai provider

Manage AI providers

### Synopsis

Manage AI providers.

The default provider is `gitkraken` (the GitKraken-hosted AI service).
You can register your own LLM provider with `gk ai provider add` to use
your own key for `gk ai` commands. Prompt templates are still fetched
from GitKraken in either case, so `gk auth login` is still required.

Use `gk ai provider use gitkraken` to revert to the default without
removing your registered providers.

Supported providers: gitkraken (default), openai, anthropic, openrouter, ollama
